### v0.1.0

- Initial implementation of the DeskSync auto-refresher daemon
- Windowless background execution for silent operation on Windows
- Zero-dependency Win32 FFI bindings for special folders and shell changes
- Automated compile-time SVG-to-ICO conversion and resource linking
- Support for debounced file system events (500ms quiet window)
- GitHub Actions workflows for automated version bumping and releases
- Justfile task runner configurations with automated UPX compression
